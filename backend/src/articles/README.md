# مقالات ات‌مت

مقالات در collection مستقل `articles` در MongoDB نگهداری می‌شوند. رسپی‌ها همچنان در JSON بخش `web` هستند و در مسیر `/recipes` نمایش داده می‌شوند؛ مجله مسیر `/articles` دارد.

## API

- عمومی: `GET /api/public/articles`، `GET /api/public/articles/categories` و `GET /api/public/articles/:slug`؛ فقط مقالهٔ منتشرشده را برمی‌گردانند.
- ادمین/سوپرادمین با JWT: فهرست و جزئیات در `/api/articles`، ساخت با POST، ویرایش با PATCH `/:id`، انتشار/بازگردانی با PATCH `/:id/status` و بدنهٔ `{ "status": "published" }` یا `draft`، حذف پیش‌نویس با DELETE `/:id`.
- تصاویر صرفاً از `POST /api/storage/images` با دستهٔ `general` وارد می‌شوند. مقاله `key` و متن جایگزین را ذخیره می‌کند؛ پاسخ عمومی URL ثبت‌شده در مخزن را برمی‌گرداند. سایت از پراکسی همان‌مبدأ `/media` استفاده می‌کند.

برای انتشار: ۷۰۰ تا ۱۵۰۰ کلمه، کاور، خلاصه، مقدمه، دست‌کم سه بخش و منبع لازم است. شمارش از مقدمه، پاراگراف‌ها و پرسش/پاسخ‌ها انجام می‌شود و آدرس پیوندها محاسبه نمی‌شود. آدرس مقاله پس از اولین انتشار ثابت می‌ماند. ذخیرهٔ ویرایش مقالهٔ منتشرشده بلافاصله سایت را به‌روز می‌کند. داده‌های بدنه HTML اجرا نمی‌کنند.

درون متن فقط پیوند محلی `[عنوان](/articles/slug)`، `/recipes/slug` و `/flavors/slug` پشتیبانی می‌شود؛ `[۱]` به منبع شمارهٔ یک وصل می‌شود. منبع بیرونی در آرایهٔ منابع قرار می‌گیرد. `relatedRecipeSlugs` هم رسپی را زیر مقاله نمایش می‌دهد و هم مقاله را در صفحهٔ رسپی معرفی می‌کند. مقالات مرتبط منتشرنشده در پیشنهادهای عمومی دیده نمی‌شوند.

## نگهداری محلی

پنل مدیریت در `/articles` برنامهٔ `admin-web` است. پیش‌فرض سایت ۳۰۰۲، API ۳۰۱۰ و ادمین ۳۰۰۱ است؛ در صورت اشغال پورت ادمین: `npm exec next dev -- -p 3003` را از `admin-web` اجرا کنید. مقصد API از `ATMAT_API_URL` و مقصد مشاهدهٔ سایت از `NEXT_PUBLIC_SITE_URL` قابل تنظیم‌اند.

از ریشهٔ مخزن `npm run seed:articles` ده مقاله را بدون بازنویسی موارد موجود درج می‌کند؛ فایل seed در `backend/seeds/articles.json` است و به اشیای MinIO موجود نیاز دارد. این دستور جایگزین بکاپ نیست: MongoDB، MinIO و manifest باید با هم نگهداری شوند.

آزمون چرخهٔ مقاله: از `backend` دستور `node --env-file=.env scripts/check-articles.mjs`. نیازمند API فعال و همان ده مقاله است؛ رکورد موقت آزمایشی می‌سازد، انتشار/بازگردانی/حذف و اعتبارسنجی را بررسی می‌کند و آن رکورد را پاک می‌کند.

محتوای آغازین در پنج دستهٔ تغذیه، سلامتی، هلث فود و سبک زندگی، ورزش و دنیای آبزیان است. تصاویر تولیدشده تصویرسازی‌اند و سند واقعی کارخانه، متخصص یا تأمین‌کنندگان برند نیستند؛ این توضیح کنار منابع عمومی نمایش داده می‌شود. اطلاعات تغذیهٔ محصول باید با برچسب معتبر تطبیق داشته باشد.
