# مقالات ات‌مت

مقالات در collection مستقل `articles` در MongoDB نگهداری می‌شوند و مجلهٔ سایت در مسیر `/articles` نمایش داده می‌شود.

## API

- عمومی: `GET /api/public/articles`، `GET /api/public/articles/categories` و `GET /api/public/articles/:slug`؛ فقط مقالهٔ منتشرشده را برمی‌گردانند.
- ادمین/سوپرادمین با JWT: فهرست و جزئیات در `/api/articles`، فهرست سبک با `?summary=1`، ساخت با POST، ذخیرهٔ پیش‌نویس با PATCH `/:id`، انتشار یا برداشتن از سایت با PATCH `/:id/status` و بدنهٔ `{ "status": "published" }` یا `draft`، حذف پیش‌نویس با DELETE `/:id`.
- تصاویر صرفاً از `POST /api/storage/images` با دستهٔ `general` وارد می‌شوند. مقاله `key` و متن جایگزین را ذخیره می‌کند؛ پاسخ عمومی URL ثبت‌شده در مخزن را برمی‌گرداند. سایت از پراکسی همان‌مبدأ `/media` استفاده می‌کند.

برای انتشار، متن باید ۷۰۰ تا ۱۵۰۰ کلمه باشد و کاور، خلاصه، مقدمه، دست‌کم سه بخش و منبع داشته باشد. شمارش از مقدمه، پاراگراف‌ها و پرسش/پاسخ‌ها انجام می‌شود و آدرس پیوندها محاسبه نمی‌شود. آدرس مقاله پس از اولین انتشار ثابت می‌ماند. ویرایش مقالهٔ منتشرشده در پیش‌نویس جدا ذخیره می‌شود و با انتشار دوباره به سایت می‌رود. پاسخ ادمین `hasUnpublishedChanges` را برمی‌گرداند. پنل در درخواست‌های ویرایش، انتشار و حذف، مقدار `updatedAt` را در `If-Match` می‌فرستد تا ویرایش نشست دیگری بازنویسی نشود. داده‌های بدنه HTML اجرا نمی‌کنند.

درون متن فقط پیوند محلی `[عنوان](/articles/slug)`، `/recipes/slug` و `/flavors/slug` پشتیبانی می‌شود؛ `[۱]` به منبع شمارهٔ یک وصل می‌شود. منبع بیرونی در آرایهٔ منابع قرار می‌گیرد. `relatedRecipeSlugs` هم رسپی را زیر مقاله نمایش می‌دهد و هم مقاله را در صفحهٔ رسپی معرفی می‌کند. مقالات مرتبط منتشرنشده در پیشنهادهای عمومی دیده نمی‌شوند.

## نگهداری محلی

پنل مدیریت در `/articles` برنامهٔ `admin-web` است. پیش‌فرض سایت ۳۰۰۲، API ۳۰۱۰ و ادمین ۳۰۰۱ است؛ در صورت اشغال پورت ادمین: `npm exec next dev -- --hostname 127.0.0.1 -p 3004` را از `admin-web` اجرا کنید. مقصد API از `ATMAT_API_URL` و مقصد مشاهدهٔ سایت از `NEXT_PUBLIC_SITE_URL` قابل تنظیم‌اند.

دستور `npm run seed:articles` از ریشهٔ مخزن، مقاله‌های تازهٔ `backend/seeds/articles.json` را درج و منتشر می‌کند و به تصاویر ثبت‌شده در MinIO نیاز دارد. برای بکاپ، MongoDB، MinIO و manifest را با هم نگه دارید.

آزمون چرخهٔ مقاله با `node --env-file=.env scripts/check-articles.mjs` از پوشهٔ `backend` اجرا می‌شود. به API فعال و مجموعهٔ منتشرشدهٔ seed نیاز دارد و اعتبارسنجی، انتشار، بازگردانی و حذف را با یک رکورد موقت بررسی می‌کند.

محتوای آغازین در پنج دستهٔ تغذیه، سلامتی، هلث فود و سبک زندگی، ورزش و دنیای آبزیان است. تصاویر تولیدشده تصویرسازی‌اند و سند واقعی کارخانه، متخصص یا تأمین‌کنندگان برند نیستند؛ این توضیح کنار منابع عمومی نمایش داده می‌شود. اطلاعات تغذیهٔ محصول باید با برچسب معتبر تطبیق داشته باشد.
